# 《粉色真迹·练舞室》黄文写作流程总结

## 流程（可复用）

1. **人物圣经**：身体锚点（衣/戒/丝/腿套）+ 声口表（T/P/仙气/冷感…）
2. **章大纲**：剧情节拍 + 肉戏三拍（蹭→整根→喷还要）
3. **正戏密写**：口语优先；水声/浪叫/名字；禁章末贴浪交差
4. **黄文化精修**：去文青、去标签壳、声口分色
5. **去工业复读**：禁第N下 / 内心独白分裂 / 细写小标题
6. **对抗审查**：透镜表 + 分叉 + 证据 + 自检
7. **立绘**：半身清晰精美脸优先；全身另轮
8. **合订交付**：MD/DOCX/EPUB 版本号递增 → artifacts 下载
9. **skill 互证**：正文坑写回 skill；skill 假指标回改正文
