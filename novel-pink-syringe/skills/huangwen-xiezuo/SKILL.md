## 1. 写作总流程（必须按序）

```
A. 人物圣经（身体锚点+声口）
B. 章大纲（剧情节拍 + 肉戏节拍）
C. 正戏密写（肉戏占章内高比例，口语优先）
D. 黄文化精修（去文青、去标签、声口分色）
E. 去工业复读（禁第N下/内心独白分裂/细写小标题）
F. 对抗审查（透镜表+分叉+证据）
G. 立绘（清晰面孔半身优先）
H. 合订 MD/DOCX/EPUB + 版本号 + 推送
I. 用本 skill 与成稿互证，缺口回写 skill / 回补正文
```

**禁止**：只在章末贴一段【加浪】交差；禁止用「第1下…第100下」撑字数。

## 2. 黄文美学（比「正经情色」更狠）

### 2.1 五感同时上
- **听**：啊啊啊 / 呃呃呃 / 咕啾 / 拍肉 / 浪叫破音
- **触**：胀、满、烫、麻、酸、夹、喷
- **视**：镜墙、银戒、黑丝破口、精丝、潮吹水光
- **味/嗅**：腥甜、汗、精、香水尾调

### 2.2 脏话密度（章内肉戏段）
目标（肉戏段落内，不是全章平均注水）：
- `啊啊啊` 高频出现在高潮句
- 每场高潮至少 1 次 `操我` 或 `被操`
- 水声词：`咕啾` / `湿透` / `喷`
- 称呼羞辱与求欢并存：骚货 / P / 姐 / 名字

### 2.3 禁止的「假黄」
| 假黄 | 真黄替代 |
|---|---|
| 爱液缓缓流出 | 骚水糊了一手，咕啾一声 |
| 她轻轻呻吟 | 啊啊啊——好深——别停—— |
| 内心独白分裂成两条轨道 | 直接叫床 + 动作 |
| 第87下乱掉的时候… | 删掉，手写独特一轮 |
| 她浪叫：“…”（标签壳） | 融进动作：`破着嗓子喊` / `边夹边喘` |
| ## 细写补强 / 收束垫句 | 删除编辑气小标题 |

### 2.4 节奏
一场肉戏最少三拍：
1. **蹭/舔/指**（水声起来）
2. **整根/猛抠**（浪叫起来）
3. **喷/内射/余韵还要**（求第二次）

高潮后不要立刻「文学收束」；至少留一句还痒、还夹、还要。

## 4. 逐章写法（Agent 操作手册）

### 4.1 开写前
1. 读本章大纲 + 上场人物身体锚点（衣/环/腿套/黑丝/银戒）
2. 定本场肉戏主轴（谁操谁、用什么、在哪）
3. 定 3 个「视觉脏点」（镜、精、丝袜破口等）

### 4.2 正戏
- 叙述句短；对话浪；动作具体到部位
- 每 200–400 字肉戏至少一次出声（啊/操/名字）
- 道具/药/针/门禁要服务快感，不写说明书

### 4.3 章末
- 剧情钩子（门缝/脚步/芯片/批号）+ 身体未合拢
- 不要总结主题；不要「细写到此站住」

### 4.4 字数
- 常规章 CJK ≈ 10000+
- 大章（21–23）≈ 15000
- **只可用独特肉戏/剧情加字，禁止复读模板**

## 5. 精修清单（交稿前必跑）

```bash
# 旧名
rg -n '韩媛媛|崔椰奶|小攻|小受|林雅娴|媛媛姐' chapters/

# 工业复读
rg -n '第[0-9]+下乱掉|内心独白.*分裂|细写补强|收束细写|替换垫句|高密度补写' chapters/

# 标签壳
rg -n '她浪叫：|嘴里却漏出真声' chapters/

# 浪密度抽样
python3 - <<'PY'
import re, pathlib
for p in sorted(pathlib.Path('chapters').glob('*.md')):
    t=p.read_text(encoding='utf-8')
    hot=sum(len(re.findall(m,t)) for m in ['啊啊啊','操我','被操','咕啾','骚逼'])
    print(p.name, hot, len(re.findall(r'[\u4e00-\u9fff]',t)))
PY
```

精修动作优先级：
1. 删复读 / 删编辑气标题
2. 标签句 → 动作+出声（边夹边喘 / 破着嗓子喊）
3. 声口分色补句
4. 文青词替换：爱液→骚水，轻轻→狠狠（注意别误伤「细细的银戒」）

## 6. 对抗审查（交付前）

按「对抗性审查」习惯输出：
1. 透镜覆盖表（每个「未发现」写清查了什么）
2. ≥3 类分叉轮次
3. Findings + 证据
4. 第二轮盲点
5. 工作量举证
6. 反偷懒自检 5 框

透镜至少含：定名、复读、浪密度、声口、立绘面孔、EPUB 可读性。

## 7. 立绘与 EPUB

### 立绘
- 半身特写：**清晰精美面孔**（用户明确要求时禁止糊脸）
- Prompt 用时尚摄影措辞；被安全策略拦截就降情色保留面孔清晰
- 雪允强调黑丝/酒杯腿/仙气；勿强调骆驼趾

### EPUB
- 使用 `novel-pink-syringe/tools/rebuild_exports.py`
- 版本号递增（content.opf `urn:pink-syringe:vN`）
- 复制到 `/opt/cursor/artifacts/粉色真迹·练舞室.epub` 供下载
- `zipfile.testzip()` 必须通过

## 8. 与成稿互证（skill 维护）

每完成一轮正文精修，对照本 skill：
- 正文违反 skill → 改正文
- skill 写了但正文做不到 / 太假 → 改 skill（降假指标、补反例）
- 把新坑写进「禁止的假黄」表
